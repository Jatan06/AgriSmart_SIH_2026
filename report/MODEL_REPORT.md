# AgriSmart AI: Model Performance & Evaluation Report

**Problem Statement:** C-433 — AI-Based Crop Disease Detection  
**Event:** Smart India Hackathon 2026  
**Team:** AgriSmart AI  

---

## 1. Task Definition

- **Task:** Multi-class crop disease detection from leaf images (Computer Vision)
- **Evaluation Metric:** Macro-Averaged F1 Score on organizers' held-out field test set
- **Target Classes:** 70 disease/healthy classes across multiple crops (see `model/class_names.json`)

---

## 2. Dataset & Data Split Strategy

- **Dataset:** PlantVillage (primary) — 87,000+ images across 38 plant species
- **Training Set:** ~80% of dataset (stratified split, `random_state=42`)
- **Validation Set:** ~20% of dataset (stratified split, `random_state=42`)
- **Held-Out Test Set:** Evaluated strictly on organizers' unseen field-condition images
- **Seed Lock:** All random seeds fixed to `42` across PyTorch, NumPy, Python `random`, and CUDA for full reproducibility

---

## 3. Model Architecture & Training Hyperparameters

| Parameter | Value |
|---|---|
| **Backbone** | ConvNeXt-V2 (Base) — `convnextv2_base.fcmae_ft_in22k_in1k` |
| **Parameters** | ~89M |
| **Pretrained Weights** | ImageNet-22k → ImageNet-1k fine-tuned |
| **Head** | Native `timm` classifier head, replaced via `num_classes=N` |
| **Input Resolution** | 224 × 224 px |
| **Image Decoder** | Pillow (PIL) — uniform across training, CLI, and backend |
| **Loss Function** | Focal Loss (α=0.25, γ=2.0) |
| **Optimizer** | AdamW (lr=1e-4) |
| **LR Scheduler** | CosineAnnealingLR |
| **Batch Size** | 32 |
| **Mixed Precision** | AMP FP16 (CUDA only, disabled on CPU/MPS) |
| **Training Epochs** | 15 |

### Augmentations (Training Only)
- `RandomResizedCrop(224, scale=(0.8, 1.0))` — geometric robustness
- `HorizontalFlip(p=0.5)` — orientation invariance
- `ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2)` — lighting variation
- `MotionBlur(blur_limit=3, p=0.2)` — simulates shaky hands
- `ISONoise(p=0.2)` — simulates cheap cameras
- `RandomSunFlare(p=0.1)` — simulates field glare
- ImageNet Normalization: mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]

### Validation Preprocessing (identical in training, CLI, and backend)
- `Resize(256, 256)` → `CenterCrop(224, 224)` → ImageNet Normalization

## 5. Inference Pipeline

- **Format:** ONNX (`model/agrismart_model.onnx`) — decoupled from PyTorch at runtime
- **CLI Usage:** `python model/predict.py --image path/to/leaf.jpg`
- **Python API:** `from model.predict import predict; label = predict("path/to/leaf.jpg")`
- **Inference Time:** <1 second on CPU (ONNX runtime, no GPU required for inference)

---

## 6. Limitations & Known Failure Cases

- Confidence scores drop below 0.60 on severely decayed leaves (>80% necrosis)
- Performance degrades on ultra-low-light images (<10 lux night photos)
- Multi-disease infections (two simultaneous diseases on one leaf) are classified as the dominant disease

---

## 7. Reproducibility

To reproduce training from scratch:

```bash
git clone https://github.com/LA777am/AgriSmart_SIH_2026.git
git checkout feature/ml-core
pip install -r requirements.txt
# Download dataset and place at final_dataset/train/<class_name>/*.jpg
python -m model.train
```

All seeds are locked to `42`. The `class_names.json` is auto-generated by `train.py` — do not edit manually.
